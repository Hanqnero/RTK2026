# MeArm + PCA9685: что менять потом

Этот файл - памятка по локальной настройке манипулятора через плату PCA9685.

Главная идея:

```text
MeArm считает движение
-> адаптер отправляет pulse_us
-> PCA9685 по I2C генерирует PWM
-> сервоприводы двигаются
```

## 1. Что менять в коде в первую очередь

Основной файл для первого запуска:

```text
src/test/main_mearm_pca9685_test.cpp
```

Вверху файла есть блок:

```text
МЕНЯТЬ НАСТРОЙКИ ЗДЕСЬ
```

Сначала меняй только его.

## 2. I2C-адрес PCA9685

Настройка:

```text
kPca9685Address
```

Обычно:

```text
0x40
```

Если I2C scanner найдет другой адрес, например `0x41`, поменяй только это значение.

## 3. Частота сервоприводов

Настройка:

```text
kServoFrequencyHz
```

Для обычных сервоприводов оставь:

```text
50
```

Это значит 50 Hz, то есть один PWM-период примерно 20 ms.

## 4. Каналы PCA9685

Настройки:

```text
kBaseChannel
kShoulderChannel
kElbowChannel
kClawChannel
```

Это не пины Arduino.

Это номера выходов на плате PCA9685:

```text
0, 1, 2, ... 15
```

Текущая раскладка:

```text
base     -> канал 0
shoulder -> канал 1
elbow    -> канал 2
claw     -> канал 3
```

Если при тесте двигается не тот сустав, поменяй номера каналов в этом блоке.

## 5. Что менять, если серва едет слишком далеко

В тестовом файле есть строка-комментарий:

```text
pwm_output.setPulseLimits(1100, 1900);
```

Можно раскомментировать ее и сузить диапазон.

Например:

```text
1100..1900
```

безопаснее, чем:

```text
1000..2000
```

Для первого запуска лучше не давать полный ход, чтобы рука не уперлась в механику.

## 6. Что менять, если плата не находится

Проверить:

```text
PCA9685 VCC -> Arduino 5V
PCA9685 GND -> Arduino GND
PCA9685 SDA -> Arduino Mega D20
PCA9685 SCL -> Arduino Mega D21
OE -> GND
```

И обязательно:

```text
земля Arduino == земля питания серв
```

## 7. Питание сервоприводов

Не питай сервы от Arduino.

Правильно:

```text
отдельный 5-6V блок питания -> PCA9685 V+
GND блока питания -> общий GND
```

Arduino питает только логику PCA9685 через `VCC`.

## 8. Как запускать тестовую сборку

Конфигурация:

```bash
cmake -S . -B build-mearm-pca9685 -G Ninja \
  -DCMAKE_BUILD_TYPE=Debug \
  -DCMAKE_EXPORT_COMPILE_COMMANDS=ON \
  -DCMAKE_TOOLCHAIN_FILE=toolchains/avr-system.cmake \
  -DAVR_TOOLCHAIN_ROOT=/opt/homebrew/Cellar/avr-gcc@9/9.5.0 \
  -DAVR_STDLIB_INCLUDE_DIR=/opt/homebrew/Cellar/avr-gcc@9/9.5.0/avr/include \
  -DROBOT_MEARM_PCA9685_TEST=ON
```

Сборка:

```bash
cmake --build build-mearm-pca9685
```

Прошивка через существующий `flash` target:

```bash
cmake --build build-mearm-pca9685 --target flash
```

Если порт другой, при конфигурации добавь:

```text
-DUPLOAD_PORT=/dev/cu.usbmodemXXXX
```

## 9. Самый безопасный порядок проверки

1. Проверить I2C scanner: увидеть PCA9685.
2. Подключить один сервопривод к каналу 0.
3. Проверить 1500 us, потом 1400 us, потом 1600 us.
4. Проверить каналы 0, 1, 2, 3.
5. Только потом запускать MeArm demo.
6. Если механика упирается - сразу выключить питание серв и сузить pulse limits.

## 10. Где лежит низкоуровневый драйвер

Интерфейс:

```text
include/mearm_servo_output.h
```

PCA9685-класс:

```text
include/pca9685_servo_output.h
src/pca9685_servo_output.cpp
```

Менять туда надо только если ты хочешь менять сам принцип работы PCA9685.
Для обычной настройки адреса, каналов и безопасного диапазона лучше трогать только тестовый файл.
