# Энкодер MT6701 (магнитный модуль)

На роботе RTK2026 используются модули магнитного энкодера **MagnTek MT6701**.

## Параметры MT6701

- **Тип:** магнитный датчик угла (Hall), 0–360°
- **Режимы выхода:** ABZ (инкрементальный), бинарный, I2C/SSI (абсолютный угол), аналог/PWM, UVW
- **Разрешение (ABZ):** 1–1024 импульсов на оборот (PPR), настраивается
- **Разрешение (бинарный):** до 1024 импульсов / 4096 шагов на оборот
- **Абсолютный угол (I2C/SSI):** 14 бит
- **Напряжение:** 3,3–5 В
- **Скорость:** до 55 000 об/мин

Для одометрии колёс обычно используют режим ABZ (импульсы на оборот). Количество тиков на метр пути зависит от PPR и радиуса колеса.

## Связь с base_controller: ticks_per_meter

В `rtk2026_base` параметр `ticks_per_meter` задаёт, сколько тиков энкодера приходится на 1 м пути **базы** (одно колесо даёт тики, база движется на полусумме левого и правого).

Формула для одного колеса:

```
ticks_per_meter = PPR / (2 * pi * wheel_radius)
```

где `wheel_radius` в метрах, PPR — импульсов на оборот (для MT6701 в режиме ABZ можно задать до 1024).

Пример: радиус колеса 0,026 м, PPR = 1024:

- Длина окружности = 2 * pi * 0,026 ≈ 0,163 м  
- ticks_per_meter ≈ 1024 / 0,163 ≈ 6280

Если в конфиге указано 1000, это либо калиброванное значение под реальный редуктор/колесо, либо пониженное разрешение (меньший PPR). После калибровки на реальном роботе подставьте измеренное значение в `base_controller.yaml`.

## Прошивка Arduino

Текущий код в `arduino/encoder.cpp` и `encoder.h` реализует подсчёт по двум пинам (A/B) — подходит для ABZ-выхода или квадратурного декодирования (C1, C2 на диске MT6701). При переходе на MT6701 по I2C/SSI потребуется читать абсолютный угол и считать дельты в прошивке.
