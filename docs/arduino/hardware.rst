Аппаратные интерфейсы
=====================

Актуальным источником назначений является
`arduino/include/motor_interface.h <https://github.com/Hanqnero/RTK2026/blob/main/arduino/include/motor_interface.h>`_.

Назначение выводов
------------------

.. list-table:: Arduino Mega 2560
   :header-rows: 1
   :widths: 24 24 14 38

   * - Подсистема
     - Константа
     - Pin
     - Назначение
   * - Левый мотор
     - ``LEFT_PWM_A`` / ``LEFT_PWM_B``
     - D7 / D6
     - Двухвходовой PWM–PWM канал.
   * - Правый мотор
     - ``RIGHT_PWM_A`` / ``RIGHT_PWM_B``
     - D5 / D4
     - Двухвходовой PWM–PWM канал.
   * - Левый энкодер
     - ``LEFT_ENC_CLK`` / ``LEFT_ENC_DT``
     - D20 / D2
     - Два квадратурных канала, ``INPUT_PULLUP``.
   * - Правый энкодер
     - ``RIGHT_ENC_CLK`` / ``RIGHT_ENC_DT``
     - D21 / D3
     - Два квадратурных канала, ``INPUT_PULLUP``.
   * - Сонар
     - ``SONAR_VCC_PIN``
     - D37
     - Программно удерживается HIGH.
   * - Сонар
     - ``SONAR_TRIG_PIN`` / ``SONAR_ECHO_PIN``
     - D39 / D41
     - Trigger и измерение длительности echo.
   * - Сонар
     - ``SONAR_GND_PIN``
     - D43
     - Программно удерживается LOW.
   * - Serial
     - UART0 RX/TX
     - D0 / D1
     - USB-команды и телеметрия, 115200 бод.

.. warning::

   Существующий ``arduino/pinout.md`` указывает для левого энкодера D18/D19 и
   для правого D20/D21. Текущий компилируемый заголовок задаёт D20/D2 и D21/D3.
   До подключения оборудования нужно выбрать одну разводку и синхронно
   исправить код, схему и таблицу pinout.

Параметры механики и энкодеров
------------------------------

.. list-table:: Калибровочные константы
   :header-rows: 1
   :widths: 36 18 46

   * - Константа
     - Значение
     - Влияние
   * - ``kWheelRadiusM``
     - 0.024 м
     - Масштаб линейной скорости и пройденного расстояния.
   * - ``kTrackWidthM``
     - 0.195 м
     - Масштаб угловой скорости.
   * - ``kEncoderCountsPerMotorRev``
     - 1300
     - Перевод дельты энкодера в обороты. Комментарий называет значение
       эффективным после квадратурного декодирования.
   * - ``kMaxMotorRpm``
     - 960 rpm
     - Паспортный предел; непосредственно в ограничении PID сейчас не
       используется.
   * - ``kControlPeriodMs``
     - 25 мс
     - 40 Гц измерения скорости, PID, одометрии и телеметрии. Предел снизу
       задаёт разрешение энкодера, а не стоимость расчёта.
   * - ``kCommandTimeoutMs``
     - 500 мс
     - Dead-man Arduino.

Знаки моторов и энкодеров
-------------------------

Текущие значения:

.. code-block:: cpp

   kLeftMotorReverse   = true;
   kRightMotorReverse  = true;
   kLeftEncoderReverse = true;
   kRightEncoderReverse = false;

Правильная комбинация определяется не визуальным направлением вала, а
инвариантом интерфейса: при движении вперёд обе измеренные скорости колёс
должны быть положительными. Проверка выполняется ``verify_signs.py`` при
поднятом над землёй роботе.

EncoderCounter
--------------

Класс
`EncoderCounter <https://github.com/Hanqnero/RTK2026/blob/main/arduino/include/encoder.h>`_
оборачивает ``uEncoder``.

``begin()``
   Выбирает ``Step1`` и применяет аппаратную инверсию направления.

``handleInterrupt()``
   Вызывает ``tickISR``; при зафиксированном шаге увеличивает одновременно
   ``_delta`` и накопительный ``_count``.

``readAndResetDelta()``
   Атомарно относительно прерываний копирует ``_delta`` и обнуляет его.

``readCount()``
   Возвращает накопительный 64-битный счётчик. Сейчас чтение не закрыто
   ``noInterrupts()``, поэтому на 8-битном AVR оно не гарантирует атомарный
   снимок всех восьми байтов.

Сонар
-----

``configureSonar`` настраивает питание и линии. ``sonarObstacleDetectedNow``
выполняет одно измерение, а ``sonarObstacleDetected`` кэширует результат и
обновляет его не чаще одного раза в ``kSonarSamplePeriodMs = 60`` мс.
Расстояние вычисляется как ``echo_us / 58`` сантиметров; отсутствие echo
возвращает ``-1`` и не считается препятствием.

BMI270
------

``Bmi270I2c`` реализует загрузку конфигурационного blob, проверку chip ID
``0x24`` и чтение 12 байт accel/gyro. Тест пробует адреса ``0x68`` и ``0x69``.

.. attention::

   Hardware I2C Arduino Mega использует D20/D21, но эти же выводы текущий
   ``motor_interface.h`` назначает энкодерам. Поэтому BMI270 и основной
   моторный firmware нельзя использовать вместе без изменения разводки или
   переноса одного из интерфейсов.
