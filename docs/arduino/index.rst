Прошивка Arduino Mega
=====================

Каталог ``arduino/`` содержит основную прошивку ATmega2560, два стендовых
варианта, собственную сборку CMake/AVR и Python-инструменты для проверки
Serial-телеметрии. Код Arduino не является ROS-узлом: граница с ROS проходит
по фиксированным бинарным структурам ``ControlPacket`` и ``TelemetryPacket``.

Поток одного цикла
------------------

.. code-block:: text

   readLatestCommand()
          │
          ├── ограничение linear/angular
          └── обновление last_command_ms
                    │
                    ▼
   applyCommandTimeout()
                    │
                    ▼
   runControlCycle() каждые kControlPeriodMs
          ├── снять дельты энкодеров
          ├── подавить малые/симметричные возмущения
          ├── вычислить скорости колёс и корпуса
          ├── проинтегрировать x, y, heading
          ├── проверить сонар
          ├── вычислить linear/angular PID
          ├── смешать PID-выходы в left/right PWM
          └── передать TelemetryPacket

Текущий период ``kControlPeriodMs = 100`` соответствует **10 Гц**, хотя
комментарий рядом с константой предлагает перейти к 50–100 Гц. Все формулы
скорости в текущей реализации предполагают ровно этот фиксированный период.

Критические ограничения текущего протокола
------------------------------------------

* нет преамбулы, длины, версии, sequence number и CRC;
* после потери одного байта принимающая сторона не умеет восстановить границу
  пакета;
* ``ControlPacket`` не проверяется на NaN/Inf в прошивке;
* скорость вычисляется по номинальному ``kControlPeriodMs``, а не по реально
  измеренному интервалу;
* ``pulseIn`` сонара может блокировать цикл до ``kSonarEchoTimeoutUs``;
* BMI270 сейчас входит только в отдельную тестовую прошивку, но не в основной
  контур управления.

Эти пункты описывают фактические границы реализации и должны учитываться при
интерпретации одометрии и телеметрии.
