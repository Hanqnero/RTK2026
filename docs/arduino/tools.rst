Диагностические инструменты Arduino
===================================

Python-скрипты запускаются напрямую и не требуют ROS. Общие зависимости:
``pyserial``; для графиков teleop также используется ``matplotlib``.

``log_telemetry.py``
--------------------

Читает 32-байтовые пакеты, декодирует их в ``TelemetrySample``, печатает
значения и при необходимости записывает CSV.

.. automodule:: log_telemetry
   :members:
   :undoc-members:
   :show-inheritance:

``teleop_keyboard.py``
----------------------

Автономный клавиатурный teleop для отладки Arduino без ROS. Он формирует тот
же бинарный ``ControlPacket``, читает телеметрию, умеет вести лог и строить
график. Значение ``TRACK_WIDTH_M`` используется только для преобразования
желаемых скоростей отдельных колёс во внешнюю команду linear/angular; оно
должно совпадать с механикой прошивки.

.. automodule:: teleop_keyboard
   :members:
   :undoc-members:
   :show-inheritance:

``verify_signs.py``
-------------------

Подаёт по очереди положительную и отрицательную команду на каждое колесо и
проверяет знак соответствующей сырой энкодерной дельты. Перед запуском робот
обязательно поднимается над поверхностью.

   :undoc-members:

``test_motor_control.py``
-------------------------

Посылает заданную последовательность linear/angular-команд, принимает
телеметрию и сохраняет измерения для последующего анализа PID и знаков.

``test_telemetry.py``
---------------------

Проверяет стабильное чтение фиксированных 32-байтовых записей и печатает
декодированные поля. Полезен до запуска ROS bridge.

``read_bmi270_console.py``
--------------------------

Читает текстовый вывод отдельной BMI270 test firmware, фильтрует строки и
может ограничить длительность/количество выборок.

Стендовые прошивки
------------------

``main_direct_motor_test.cpp``
   Последовательно проверяет левый и правый мотор в обоих направлениях,
   затем оба мотора вместе. Каждые 100 мс печатает CSV с PWM и дельтами.

``main_bmi270_test.cpp``
   Инициализирует BMI270 на 400 кГц, печатает raw accel/gyro каждые 100 мс и
   повторяет инициализацию раз в секунду после ошибки.
