# Пакет `rtk2026_slam` (SLAM Toolbox и карта)

## Назначение

Обёртка и конфигурация для `slam_toolbox`:

- онлайн SLAM по данным лидара (`/scan`);
- публикация карты `/map`;
- TF `map` → `odom` (либо статического, либо динамического).

## Основные компоненты

- `launch/slam.launch.py`:
  - поднимает `slam_toolbox` с параметром `use_sim_time`;
  - выбирает конфиг (`online_async.yaml` или аналогичный).
- `launch/slam_fake_odom.launch.py`:
  - вариант, который также поднимает вспомогательные узлы (`fake_odom`, TF, clock) для чисто симуляционного/one‑container сценария.
- Конфигурационные YAML:
  - параметры фильтров, минимальное/максимальное расстояние лидара;
  - стратегия обновления карты (период, rolling window — если используется).

## Основные топики и TF

- Вход:
  - `/scan` (`sensor_msgs/LaserScan`);
  - `/odom` (если SLAM учитывает движение от одометрии).
- Выход:
  - `/map` (`nav_msgs/OccupancyGrid`);
  - TF `map` → `odom`.
