# Пакет `rtk2026_driver` (драйвер Arduino и низкоуровневый IO)

## Назначение

Обеспечивает связь с Arduino‑платой и другими устройствами по UART/Serial:

- приём отчётов энкодеров и состояния;
- отправка команд моторам;
- преобразование бинарного протокола в ROS2‑сообщения (`rtk2026_interfaces`).

## Основные компоненты

- Узел «мост» RPi ↔ Arduino (UART):
  - читает/пишет данные по сериалу;
  - парсит/формирует структуры по протоколу из `docs/protocol_arduino.md`;
  - публикует/подписывается на ROS2‑топики для `rtk2026_base`.
- Конфиги типа `config/arduino_bridge.yaml`:
  - скорость порта, имя устройства (`serial_port`);
  - частоты обновления и таймауты.

## Основные топики

- Вход:
  - команды на моторы от `rtk2026_base` (через интерфейсы);
- Выход:
  - отчёты энкодеров и статуса, используемые в `rtk2026_base` и локализации.
