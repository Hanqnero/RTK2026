# Пакет `rtk2026` (мета и общие сообщения)

## Назначение

Метапакет для рабочего пространства RTK2026. Содержит общие интерфейсы (через `rtk2026_interfaces`), базовые launch’и верхнего уровня и зависимости между пакетами.

## Основные компоненты

- `package.xml` — объявляет зависимости между всеми пакетами RTK2026.
- (При наличии) launch‑файлы верхнего уровня для демонстраций/тестов.

## Когда используется

- При установке и сборке workspace (через `colcon build`).
- Как точка входа для high‑level сценариев, которые используют несколько пакетов сразу.
