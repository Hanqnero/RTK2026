# Пакет `rtk2026_description` (URDF и визуализация)

## Назначение

Хранит описание робота RTK2026:

- URDF/Xacro модели корпуса и сенсоров;
- RViz‑конфиги для визуализации;
- материалы и параметры геометрии.

## Основное содержимое

- `urdf/rtk2026.urdf.xacro` — главное описание робота для реального мира/Isaac.
- RViz‑конфиги, например:
  - `rviz/rtk2026.rviz` — базовый просмотр;
  - `rviz/rtk2026_sim_slam.rviz` — SLAM/навигация (карта, план, траектория).

## Использование

- Пакет подключается в `robot_state_publisher` через `rtk2026_bringup` и `rtk2026_simulation`.
- Используется и в реальных сценариях (драйвер), и в симуляции (визуализация модели).
