# Пакет `rtk2026_base` (базовый контроллер робота)

## Назначение

Реализует базовый контроллер дифференциального привода RTK2026:

- принимает команды линейной/угловой скорости (`/cmd_vel`);
- считает одометрию из энкодеров;
- публикует `/odom` и TF `odom` → `base_link`;
- формирует команды для драйвера моторов (через `rtk2026_driver` / UART).

## Основные узлы и launch

- Узел контроллера базы (обычно поднимается через `rtk2026_bringup/rtk2026_driver_base.launch.py`).
- Поддержка «fake encoder» для тестов без железа (`use_fake_encoder:=true`).

## Основные топики и TF

- Вход:
  - `/cmd_vel` (`geometry_msgs/Twist`) — команды линейной/угловой скорости.
  - сообщения от драйвера энкодеров (через `rtk2026_interfaces`).
- Выход:
  - `/odom` (`nav_msgs/Odometry`);
  - TF `odom` → `base_link`.
